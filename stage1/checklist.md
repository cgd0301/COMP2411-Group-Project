## J. MySQL 8.4 实现提示（不是指南原文；填 G1 的"执行方式"列时参考）

- CHECK 只能引用本行的列和确定性函数：不能用子查询，不能引用其他表，也不能用 `CURDATE()`、`NOW()` 这类函数。所以容量上限、时间重叠、状态流转这类跨行规则，应该标成"SQL 检查"或"局限"，不要写成 CHECK。
- 带 CASCADE / SET NULL 等参照动作的 FK 列，不能再用在 CHECK 里，反过来也一样。
- InnoDB 会自动给 FK 列建索引（如果还没有能用的索引）。所以 Stage 2 的"额外索引"不要只选单个 FK 列，可以选组合列或非 FK 的筛选列，或者按〔6.3〕论证现有索引。
- 事务里某条语句出错时，MySQL 一般只撤销这一条语句，整个事务不会自动回滚。所以必须显式执行 `ROLLBACK`，再查询验证。〔6.4.1〕也写了：只看到报错不能证明已经回滚。
